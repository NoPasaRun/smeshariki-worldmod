# SmesharikiWorldMod

**Роль (решение пользователя 2026-11-10): мод управления ландшафтом и отображением.** Типы мира, шейдерпак Iris, свет неба. Скрипты `tools/*.py` — **временные средства правки сохранённого мира** «Ромашковая Долина» (расщелина, пещера, лава, стрелы, ветер, снег, руины…): они лежат, чтобы при необходимости воссоздать то, что было сделано; их не развивают и не считают частью мода. Карта проекта — `../CLAUDE.md`.

Типы мира для Minecraft 26.2, Java 25, Fabric (Loom): «Остров Смешариков» (`buildmod:island`) и «Мир-океан» (`buildmod:ocean`). Выделен из BuildMod 2026-10-25. Пространство имён данных и идентификаторы остались `buildmod`, чтобы не ломать уже созданные миры (BuildMod ничего из этого больше не содержит — старый jar с островом вместе с новым не запускать: дубли регистрации).

## Правила работы

- **После каждой правки:** собрать (`./gradlew jar`) и положить `build/libs/smesharikiworld-1.0.0.jar` в `~/.minecraft/mods/smesharikiworld-1.0.0.jar`. Копировать только атомарно: `cp` во временный `.jar.tmp` в той же папке и `mv -f` (прямой `cp` поверх jar запущенной игры ломает её). Разрешено пользователем (как для BuildMod). Если сборка не прошла — ничего не копировать и сказать.
- Код: `src/main/java/com/smeshariki/world/` (`SmesharikiWorld` — регистрация, `IslandChunkGenerator`, `IslandBiomeSource`, `IslandMaps`). Карты острова: `src/main/resources/island/*.png`, строятся `tools/island_maps.py` (пути внутри скрипта абсолютные; предпросмотр `island_prev.png`, файлы `~/Изображения/*_сверху.png`). Мир-океан — только JSON в `data/buildmod/worldgen`.

## Шейдерпак Iris (2026-11-07)

- Исходники `shaderpack/shaders/` (GLSL 330 compatibility, комментарии только ASCII: Mesa на кириллице в комментариях ломался). Выбрать пак в игре: Настройки видео → Шейдеры. Первый запуск после установки Iris: пак мог появиться уже после того, как Iris прочитал папку, тогда перезапустить игру.
- Проходы: `shadow` (карта теней с сжатием к игроку), `composite` (тени, SSAO, дымка вдали), `final` (тёплый тон, насыщенность, контраст, виньетка). Настройки в `lib/settings.glsl`; по умолчанию тени и SSAO выключены (машина пользователя: Vega iGPU, 7 ГБ, 4 FPS на potato).
- Проверка компиляции без игры: все программы собираются и линкуются в OSMesa (Mesa, GL 4.5 compat) при всех сочетаниях `SHADOWS`/`SSAO`. В игре не проверено: смещения теней (прыщи/отрыв), нормали из `dFdx/dFdy` на краях силуэтов, цена выключенного прохода теней.
- В игре (2026-11-07, со слов пользователя): без `gbuffers_terrain`/`gbuffers_water` с Iris 1.11.4 + Sodium пропадала вся местность (оставались небо, сущности, свои блоки), после добавления этих двух программ (шаблон: текстура × цвет вершины × лайтмап) всё рисуется. Прорисовка 12, симуляция 10, тени и затемнение включены: около 40 FPS на Vega iGPU. Вид теней (прыщи, отрыв) не оценён.
- SSAO без ряби (2026-11-07): в `composite` AO пишется в `colortex1` с упорядоченным поворотом 4×4 (Байер) вместо шума по пикселю, в `composite1` блок 4×4 с весом по глубине усредняет шаблон и умножает цвет. Раньше 8 проб с шумом на пиксель давали «бегающее» зерно.
